The guiding principle

Noemo is a decision-support assistant, not an oracle. Every signal shows its reasoning, confidence is never certainty, and nothing it produces is financial advice.
How it works · Roadmap

Built in phases, most defensible value first.

We start where the value is clearest — journaling and analytics need no market data at all — then layer news, fundamentals and timing on top.

Phase 1 · Foundation NOW BUILDING Trade journal, performance analytics, behavioral pattern detection and a basic watchlist.
Phase 2 · News & Summarization NEXT News feed integration, LLM-powered summaries and breaking alerts via push, email or Telegram.
Phase 3 · Fundamental Analysis PLANNED Financial data integration with LLM-generated narratives and change flags.
Phase 4 · Timing & Risk PLANNED Technical conditions view, risk-management suggestions and a backtesting engine to validate any logic.
Phase 5 · Polish PLANNED Real-time charts, refined UX and an optional native desktop build.
